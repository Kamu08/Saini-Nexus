# Saini Nexus

> B2B Growth, Marketing & LinkedIn Demand Generation Engine. Built around how buyers actually buy.

## Overview
Saini Nexus is a premier B2B growth and demand generation agency based in Jaipur, Rajasthan, serving enterprise and high-growth B2B technology, industrial, and consulting clients globally.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + Custom CauseHouse Neo-Editorial Design System
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
